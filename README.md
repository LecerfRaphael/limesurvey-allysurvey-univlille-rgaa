\# AllySurvey — Thème LimeSurvey accessible RGAA/WCAG



\*\*AllySurvey\*\* est un thème LimeSurvey basé sur Vanilla, développé pour améliorer l’accessibilité des questionnaires en ligne.



Ce thème vise une meilleure prise en compte des référentiels :



\- RGAA 4.1 ;

\- WCAG 2.1 niveaux A et AA ;

\- navigation clavier ;

\- lecteurs d’écran ;

\- zoom navigateur ;

\- contrastes ;

\- structure sémantique ;

\- formulaires complexes LimeSurvey.



\## Contexte



Ce projet est mené dans le cadre d’une démarche d’amélioration continue de l’accessibilité numérique des questionnaires LimeSurvey à l’Université de Lille.



\## Compatibilité



\- LimeSurvey 6.x

\- Thème parent : Vanilla

\- Type : thème de questionnaire LimeSurvey



\## Installation



1\. Télécharger la dernière release du thème.

2\. Importer le fichier ZIP dans LimeSurvey via l’éditeur de thème.

3\. Activer le thème dans les paramètres du questionnaire.

4\. Tester le questionnaire avec clavier, lecteur d’écran et zoom navigateur.
